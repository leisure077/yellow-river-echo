### 3.5 彩陶工坊 · 无 WebGL 的转台降级 ★追问高发区

**操作**：工坊列表 → 那张副标题写着「拉坯 · 上彩 · 入窑，做一件自己的彩陶」的卡片（进去页名是**彩陶工坊**）

**看到**：预览位里一件彩陶在**自己慢慢转**，腹部压着鱼纹带，下面一行读数写着
`转台序列 · 3D 不可用：Error creating WebGL context.` —— 这行字是给人看的，不是调试残留。

**动线（60–90 秒，四步，每步都让评委看见画面真的变了）**：

1. 先让它空转 5 秒，念一句「这台模拟器跑不了 WebGL，所以立体感是 24 帧灰模转台序列帧拼出来的」
2. **左右拖一下**（手指走多少，器表那点就走多少）
3. 换**配色**（龙山黑 → 汉唐赭黄），再换**器型**（罐 → 盆 → 瓶 → 回罐）
4. 点**题字**「河」，等它转到正面，让评委看见字压在器腹上跟着转

**念**：
> "帧只负责器型的立体，颜色、纹样、题字都是 App 端每帧现罩上去的二维矢量。
> 所以换釉色、换纹样、改题字都不用重新烘帧，也不用等 3D——点下去下一帧就变。
> 五套器型 × 24 帧，随包分发一共 1.32 MiB。"

**实测口径**（被追问"卡不卡"就报数，别报感觉）：

| 项 | 实测 | 怎么量的 |
|---|---|---|
| 自动转台 | 8.3 笔/秒（120ms 一档，一档 15°） | 组件内 hilog 打点，15s 采样 124 笔 |
| 每笔间隔 | 中位 122ms / p90 123ms / 最大 138ms，无 >150ms | 同上 |
| 单笔耗时 | 中位 1ms / p90 2ms / 最大 18ms | 同上 |
| 拖动跟手 | 手势事件 82 次、间隔 ~17ms（一 vsync 一次）；拖 300 设备像素 = 85.7vp → 转角 43°，按 1:1 表面映射设计值 44.4°，差 3% | 同上 |
| 连拍不空屏 | 6 张连拍 0 张空白，纯白占比全 0 | 截屏按预览矩形裁出来数像素 |
| 五维联动 | 仰韶红主色 #b1876a/彩度 67.4 → 龙山黑 #5d5b57/彩度 6.4（纸底跟着变 #a19d95）→ 赭黄彩度 75.9；罐 776×690 → 盆 764×700 → 瓶 528×688 | 同上 |
| 题字 | 只在正面 ±60° 出现（24 档扫过：0° 暗像素 4454、60° 只剩 334、75°–285° 为 0、300° 起回升），落点 x=256+236·sinθ 逐档对得上 | 同上 + headless 复算 |

**别说的话**：不要说"这是实时渲染"。也不要说"真机上就是 3D"——真机 WebGL 仍未验证（见 §4、§5）。

## 4. 三类追问的应答口径

**Q：这个 3D 是真的还是图片？**
诚实答案：**模拟器上显示的是离线转台帧（24 帧/件，每 15° 一帧），不是实时渲染。** 引擎日志明确写着
`THREE.WebGLRenderer: A WebGL context could not be created. Reason: disabled by enterprise policy or commandline switch`，
即开发版 ArkWeb 在模拟器镜像上关闭了 GPU/vulkan 通道。渲染管线、模型、交互逻辑都是真实代码，
在支持 WebGL 的 ArkWeb 上走的是同一条路径。**不要说"真机上一定能跑"**——真机渲染我们尚未在物理设备上验证。
若被追问，答："模拟器不支持 WebGL，所以做了离线转台降级以保证演示可用；真机验证需要一台对应签名 profile 的设备。"

**Q：彩陶那件为什么能一边转一边换釉色？帧不是死的吗？**
死的只有**器型**那一张灰模。釉色、纹样、题字是每帧在 App 端现画的二维矢量：
灰模帧铺底 → `source-atop` 压一层带透明度的釉色渐变（只落在帧的不透明像素里）→
纹样带按圆柱展开切成 8 段贴上去（边缘自然压扁）→ 纸底和展示座用 `destination-over` 压到最后面。
所以换配色换纹样都不用重新烘帧，拖动也只是换一张已解码的位图。
代价说清楚：ArkUI 的画布只给了 11 个 Porter-Duff 值，没有 multiply/overlay，
釉色只能靠"半透明渐变 + source-atop"压，而且 `source-atop` 下 `fillText` 一个字都不出，
题字得改走"器身轮廓 clip + source-over"。

**Q：大禹、夺淮那两条河道有考古依据吗？**
指沙盘「注」面板第 2、3、4 条：今道与汉唐道基本走同一条线；大禹北行与宋元夺淮按史籍所载大势复原，
看的是黄河在河南怎么摆、从哪儿出入，不保证逐县可考。

**Q：为什么有件文物的出土地写"未著录"？**
双龙耳瓶与三彩马是公开馆藏扫描，源记录未载出土地，我们按"未知"如实标注，没有为了版面整齐去猜一个地方。
